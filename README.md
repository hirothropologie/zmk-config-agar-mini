# zmk-config for Agar Mini BLE

ZMK firmware config for the KBDfans Agar Mini dual-mode hotswap PCB (board `klink`, shield `agar_mini_ble`), with ZMK Studio enabled.

Based on https://github.com/openkbd/zmk-config-agar-mini-ble. Edit `config/agar_mini_ble.keymap` and push; GitHub Actions builds the `.uf2` firmware (see the Actions tab).
